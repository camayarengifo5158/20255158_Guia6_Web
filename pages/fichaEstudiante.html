Ejercicio 3: validación con expresiones regulares. Cada campo se revisa mientras se escribe usando el método test() de un objeto RegExp.

Expresiones regulares utilizadas

Una expresión regular es un patrón que describe cómo debe verse un texto. En JavaScript se escribe entre barras, por ejemplo /^\d{3}$/, y con regex.test(texto) se obtiene true si el texto cumple el patrón. ^ y $ marcan el inicio y el final, \d representa un dígito, [A-Z] un rango de letras y {n} la cantidad exacta de repeticiones.

Campo Expresión regular Ejemplo válido
Carnet/^[A-Z]{2}\d{3}$/AB001
Nombre completo/^[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+(?: [A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+)+$/Carlos Amaya
DUI/^\d{8}-\d$/01234567-8
NIT/^\d{4}-\d{6}-\d{3}-\d$/0614-010190-101-1
Fecha de nacimiento/^(0[1-9]|[12]\d|3[01])\/(0[1-9]|1[0-2])\/(19|20)\d{2}$/15/08/2005
Correo electrónico/^[\w.+-]+@[A-Za-z\d-]+(\.[A-Za-z\d-]+)*\.[A-Za-z]{2,}$/estudiante@esen.edu.sv
